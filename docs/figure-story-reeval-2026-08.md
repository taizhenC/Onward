# Figure story re-evaluation — August/September 2026

Every one of the 50 hand-authored figure stories in `lib/figures-data.ts` was re-evaluated against the authoring rules: `prompts/figure-beats.md` (anonymity through beats 0-5, no era gap, older-friend voice, the four-part bridge, truth, length), the CLAUDE.md data invariants (through-line, facet substantiability, documented age range, controlled theme vocabulary, provenance comment), the StorySpec publish rules in `lib/story-spec.ts` (direct quotes must be verbatim in `biographicalFacts`, no invented dialogue/gesture/interior monologue, no unsupported causal claims), and the critical-failure categories in `config/story-quality-policy.json`.

Method: one reviewer per figure audited the entry and web-verified its dated claims; an independent second reviewer accepted, amended, or rejected each proposed edit. A second pass then ran a blind reader on beats 0-5 only (no name, no key) and a conservative final edit gated on whether a *typical* reader could name the person; a second reviewer verified that pass too. Only reviewer-accepted edits were applied. The full per-edit trail (findings, fact checks with sources, per-edit decisions) is kept outside the repo in the review scratchpad.

Owner steps still required before these corrections can ship: (1) `config/story-recipes.json` pins `librarySnapshotSha256` to the hash of `lib/figures-data.ts`, so `check-recipe-governance` fails until a new recipe entry with the new snapshot is registered through the promotion process (README: a figure-library change is a content release with its own forward/rollback plan). (2) Re-run the real Cerebras eval (`EVAL_CONCURRENCY=1 npm run eval`); the offline stub proxy moved 96.0% → 94.1% top-1 on two age-boundary hard cases (Brontë 28→29 and Graham 48→54 are now the documented ranges). (3) `npm run seed-embeddings` — shape sentences, facets and `biographicalFacts` changed for most figures, so stored vectors fail the content-hash gate. (4) Reseed `figure_stages` (`npm run seed`) and refresh draft StorySpecs (`npm run seed-story-specs`).
