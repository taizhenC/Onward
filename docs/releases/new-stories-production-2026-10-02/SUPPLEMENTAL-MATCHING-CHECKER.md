# Supplemental real matching instrument

[eval-matching-extension.ts](eval-matching-extension.ts) measures the unchanged [twenty-case extension](matching-extension.json) through the existing `matchWithDebug` path. It supplements the authoritative original-104 real-provider content-release gate; it never writes an `evals/history` record or claims promotion authority. It does not replace or modify routes, labels, policy, prompts, models, historical ages, top-K, recipes or earlier evidence.

## Frozen inputs and bounded execution

The extension bytes are pinned to `203a6e2c69a23525fa733fe0bd481f6f4026c00b9a75a54b5fd27a5e2e5d17f7`. The original gold must retain `f87962a57990f65a8765afdcd141bbdd1c3b9f5a965d04f4810f1787d8aa2a1e`. The [projected catalog](PROJECTED-CATALOG.json) pins the exact 34 previously published stage identities from the captured writing baseline; its hash is `17336b720af3aaf5ae623043e38c118187f8f2565c3a740a0c3f70e68b88b6e4`. It is a frozen editorial projection, not a fresh live database audit.

Real execution requires an installed catalog of exactly sixty unique stages, exact equality of the ten additions to the independently reviewed proposed stage copies, unchanged original gold, a valid primary recipe manifest and matching execution configuration. The inspected implementation, cases, stage copies, proposal, projection and checker must equal their `HEAD` versions. The receipt binds the Git commit and complete input-tree hash, library-file hash, canonical eligible-catalog hash, recipe manifest hash, route hash and checker hash.

The script runs in memory mode and calls no database, Auth or public application route. It inherits provider credentials through the existing environment loader, uses the unchanged primary recipe with real provider and keyword retrieval, and rejects tagger or alphabetical-order overrides. It invokes every selected frozen case once, sequentially, without retries: twenty real requests in the default mode, or at most eighty-nine with the optional existing-case projected regression slice. The ordinary under-eighteen cases are separated as hermetic diagnostics and never submitted to public intake.

A process-only wrapper around the existing provider fetch enforces the official reranker endpoint, one request per case, 128 KiB request maximum, 64 KiB complete-response maximum and the unchanged 15-second deadline across both headers and body consumption. It preserves the request, prompt and bytes of an ordinary response. The wrapper supplies no alternative scoring or response parser. This extra body bound is disclosed because the existing provider adapter clears its fetch timer after receiving headers. Bound failures are recorded as transport failures and cannot count as successful real checks.

The checker never stores or prints feelings, prompts, provider response bodies, resonance/gap, credentials or base URLs. Per-case output contains only the frozen case index, public figure keys and bounded diagnostic scalars. The JSON receipt contains chosen key, confidence, framing, chosenBy, shortlist survival, failure classes, counts, byte counts and latency; raw exchange data stays in request memory and is discarded.

## Invocation after committing the content

Run from the isolated production checkout, after the sixty-stage content and this instrument have been committed. Keep the original-104 real gate as its separate documented command.

```powershell
# All installed sixty-stage candidates, without publication filtering:
node --import tsx docs/releases/new-stories-production-2026-10-02/eval-matching-extension.ts --catalog=installed60

# Captured thirty-four published stages plus the exact approved ten:
node --import tsx docs/releases/new-stories-production-2026-10-02/eval-matching-extension.ts --catalog=projected44

# Also measure all untouched original cases whose primary label is published,
# plus the three untouched original miss cases:
node --import tsx docs/releases/new-stories-production-2026-10-02/eval-matching-extension.ts --catalog=projected44 --include-existing
```

Each run writes a new `MATCHING-EXTENSION-<mode>-<UUID>.json` receipt in this packet. It saves partial sanitized results after every case, retains failures and never overwrites a prior run. A completed receipt remains `authoritative: false` and `promotable: false`. Its `ok` requires every selected case to pass through real reranking and all nine age-reachable figures to have at least one observed correct adult extension case. Any wrong case or fallback gives exit code one; do not discard such a receipt or relabel it as a passing instrument.

The two retained extension shortlist failures, Riis case 13 and Washington case 17, are run and remain failures even if a fallback returns some defensible adjacent figure. The extension has no alternate accepted labels. All-case, adult-only and under-eighteen metrics are separate, and no extension miss-calibration metric is claimed because this extension contains no miss cases. Every figure gets an adult-coverage record; Keller honestly reports no adult age reachability. A successful age-six diagnostic cannot count as adult coverage or a live canary.

`--include-existing` is available only with `--catalog=projected44`. It appends **69 untouched original cases**: 66 positives whose original primary expected figure is in the projected published catalog and all three original misses. Their original index, input, label, semantic/hard flags and existing `accept` arrays are preserved. A positive passes only for the original expected key or its original accepted keys; a miss passes only with partial framing, using the original evaluation convention. No label or accepted set is widened. The **35 other original positive labels** remain explicitly reported as unavailable, excluded from this reachable regression slice and never counted as correct. This projection does not resolve the historical publication holds or assert full-original-gold production coverage.

Each trial carries `dataset: extension | original104` and its original case index. The twenty-case extension and optional original regression metrics are separate, each with adult and under-eighteen splits. Combined totals are also provided. Existing regression correct counts and miss detection therefore cannot conceal the extension failures. The authoritative full-sixty original-104 trust gate remains mandatory and separate. Optional projected measurements are supplemental observed evidence, not a protected holdout or a claim of before/after production causality.
